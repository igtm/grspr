# Default key bindings

Bindings are intentionally discoverable through the footer and `?` overlay.

| Context | Key | Action |
| --- | --- | --- |
| Global | `q`, `Ctrl+C` | Quit |
| Global | `?` | Help |
| Global | `Tab`, `Shift+Tab` | Switch panel |
| Files | `j/k`, arrows | Select changed file |
| Any main panel | `J/K` | Next/previous changed file |
| Diff | `j/k`, arrows | Scroll |
| Diff | `[` / `]` | Previous/next hunk |
| Diff | `W` | Toggle ignored whitespace |
| Diff | `+` / `-` | Change context lines |
| Review | `r` | Toggle Reviewed |
| Explore | `p`, `Space`, `Enter` | Preview |
| Explore | `Ctrl+P` | File finder |
| Explore | `Ctrl+F` | ripgrep search |
| Explore | `w` | Worktree picker |
| Overlay | `Esc` | Return to diff |
